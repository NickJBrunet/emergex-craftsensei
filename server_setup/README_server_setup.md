# emergex-crafty-chat-bot

## Minecraft Server Setup

Follow these steps to set up the server for the first time.

### 1. Important Notes

-   Avoid setup in the main branch, create seperate branch for your own development.

### 2. Start the Server (Initial Run)

-   Run `server.jar`
-   This will generate the required folders and files (usually 4--5)
-   Wait about 10 seconds after execution so everything fully generates

### 3. Accept the EULA

-   Open `eula.txt`
-   Change: `eula=false` to: `eula=true`
-   Save the file

### 4. Start the Server Again

-   Run `server.jar` a second time

Server should now be running and ready to use.
to re-run, just execute `server.jar` again.
